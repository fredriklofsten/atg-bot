Lärdomar från förlorade spel

Varje avgjort spel analyseras: var hästen kom, vem som vann och om oddset rörde sig efter spelet. Boten jämför sedan sina träffar med hur många den själv räknade med, i många olika grupper. Bara skillnader som är för stora för att vara slump räknas som lärdomar. 998 spel analyserade, 77 grupper testade.
